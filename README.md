# GoIT JavaScript Homework 09 - Modern Araçlar ve Web Depolama

Bu proje, GoIT Full Stack Developer eğitimi JavaScript modülünün dokuzuncu ödevidir. Bu çalışmada; **Vite** derleyicisi kullanımı, **NPM** üzerinden paket yönetimi, JSON manipülasyonu ve tarayıcı yerel depolama (**localStorage**) mekanizmaları üzerine odaklanılmıştır.

## 📁 Proje Yapısı

Proje, modern bir geliştirme ortamı olan Vite ile yapılandırılmış ve iki ana görevden oluşmaktadır:

```text
goit-js-hw-09/
├── src/
│   ├── 01-gallery.html      # Galeri sayfası
│   ├── 01-gallery.js        # SimpleLightbox entegrasyonu
│   ├── 02-form.html         # Geri bildirim formu
│   └── 02-form.js           # LocalStorage yönetimi
├── package.json             # Bağımlılıklar ve scriptler
└── index.html               # Ana giriş noktası
